- **Tech Stack:** React.js, Node.js, Express.js, MongoDB, Redux Toolkit, JWT, Axios, Chart.js
- **Highlights:** Real-time portfolio tracking with live P&L, $10,000 starting virtual balance, 40 real US stocks across 9 sectors, secure authentication, and interactive charts.

#### 🤖 [AI Email Triage & Auto-Response System](https://github.com/Reshma-1717/Automated-Email-Triage-Response-System)
> *AI-powered system that classifies incoming emails based on priority and drafts automated responses.*
- **Tech Stack:** Python, Flask, LangChain, Transformers, NLP, OAuth2, SQLite
- **Highlights:** Automated urgency classification, context-aware draft generation using LLMs, background scheduling, and multi-user persistent inbox processing.

#### 🧠 [Autism Spectrum Disorder (ASD) Prediction](https://github.com/Reshma-1717/Autism-Prediction)
> *End-to-end machine learning pipeline to predict ASD from AQ-10 behavioral screening data.*
- **Tech Stack:** Python, Scikit-learn, XGBoost, Random Forest, Decision Tree, SMOTE, Pandas
- **Highlights:** Handled severe class imbalance using SMOTE; achieved **96% prediction accuracy** evaluated across ROC-AUC, Precision, Recall, and F1-score.

#### 🌱 [Smart Crop Recommendation System](https://github.com/Reshma-1717/smart-crop-recommendation)
> *Intelligent agricultural decision support system evaluating soil and climate metrics.*
- **Tech Stack:** Python, Scikit-learn, Random Forest, NumPy, Pandas
- **Highlights:** Optimized with k-fold cross-validation and hyperparameter tuning to achieve **95% accuracy** in recommending optimal crops for harvest.

#### 📊 [Airbnb Pricing & Availability Analysis](https://github.com/Reshma-1717/Airbnb-Pricing-Availability-Analysis)
